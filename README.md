# 💰 工资换算器 salary-convert

> 八道题，测出你的金钱人格，一键生成能晒群的卡片。

[中文](README.md) | [English](README_EN.md)

你的时薪能买几杯奶茶？月薪一万在公司里算什么水平？
答题 30 秒，给你一个又准又损的金钱人格 + 一张 1080x1440 分享卡片。

## ✨ 特性

- 🎯 **八道情境题**：存款、房租、通勤、外卖、时薪感知，全是你每天在经历的事
- 🧠 **16 种金钱人格**：从「存钱铁公鸡」到「财富自由预备役」，总有一款戳中你
- 🖼️ **一键生成分享卡片**：Canvas 本地渲染，不联网不上传，保存直接发群里
- 📦 **纯单文件**：一个 `index.html`，双击就玩，零依赖零安装

## 🚀 使用

```bash
git clone https://github.com/tomlen045/salary-convert.git
open salary-convert/index.html   # 或直接双击
```

无后端、无 API、无追踪——所有计算都在你的浏览器里完成。

## 🧩 适配场景

- 团队破冰、社群互动的开场小游戏
- 找工作谈薪前，先搞清楚自己和钱的关系
- 公众号/视频号的引流互动页（卡片自带水印位）
