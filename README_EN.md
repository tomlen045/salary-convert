# 💰 Salary Convert

> 8 questions. 1 money personality. A shareable card, generated locally.

[中文](README.md) | [English](README_EN.md)

**Salary Convert** is a tiny single-file web quiz that turns your daily money
habits (rent, commute, takeout, savings) into one of **16 money personalities** —
from "Savings Iron Rooster" to "FIRE Preparatory Squad" — and renders a
1080x1440 share card entirely in your browser.

## ✨ Features

- 🎯 8 scenario questions about everyday money trade-offs
- 🧠 16 personality results with honest (and slightly roast-y) verdicts
- 🖼️ One-click Canvas share card — nothing leaves your machine
- 📦 Pure single-file `index.html`: no backend, no API, no tracking

## 🚀 Run

```bash
git clone https://github.com/tomlen045/salary-convert.git
open salary-convert/index.html
```
